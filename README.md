# RedForge Website

**An active project documenting the design, development, and continued improvement of the Project RedForge website.**

[Visit the Live Website](https://projectredforge.com/) · [View the Broader Project](https://github.com/JPulido-cyber/Project-RedForge)

## Purpose

This repository shows how I built and continue to improve the public-facing Project RedForge website. It documents the website's development process—not just the finished product—so reviewers can see how the design, structure, content, and technical decisions evolve over time.

The repository will continue to be updated as I complete cybersecurity labs, publish project evidence, improve the user experience, and add new portfolio capabilities.

## What This Demonstrates

- Website planning, implementation, and iterative improvement
- Translating technical cybersecurity work into a clear recruiter-facing presentation
- Version control and documented development progress
- Responsive design and accessible content organization
- Connecting project reports, lab evidence, and professional development in one public platform

## Ongoing Work

- Publishing completed cybersecurity projects and sanitized evidence
- Expanding technical project pages and build documentation
- Improving navigation, accessibility, and mobile presentation
- Refining performance, search visibility, and professional branding
- Recording lessons learned as the website and portfolio develop

## Relationship to Project RedForge

This repository focuses specifically on **how the website is built and improved**. The broader [Project-RedForge repository](https://github.com/JPulido-cyber/Project-RedForge) contains the larger engineering platform, structured documentation, project records, and cybersecurity portfolio architecture.

Both are active parts of Project RedForge and serve different purposes.
